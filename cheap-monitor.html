判定规则

每只标的预设三档锚定价（极端 ≤ 甜区 ≤ 合理），取实时价后：

  • 价格 ≤ 极端 → 极度便宜：深度折价，强烈关注 / 可重仓。
  • 价格 ≤ 甜区 → 甜区：便宜，进入建仓区间，分批买入。
  • 价格 ≤ 合理 → 合理：估值合理，可小仓或继续观察。
  • 价格 > 合理 → 偏贵 / 等待：未到击球区，不追高。

数据来源：CNBC（优先）→ Nasdaq（兜底），无需 API Key。抓取失败时沿用上次有效价并标注「缓存」。锚定价为与玑哥确认的主观便宜价，非投资建议；可随时在 gen_cheap_monitor.py 的 ASSETS 中调整或新增标的。
